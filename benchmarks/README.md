# T-saur benchmarks

Percentages in every results file are archive size relative to the input: **lower is better**.

- `build_corpus.py` - builds the test corpora (downloads nothing; uses open-source texts already present locally):
  - `corpus/` - 10 "random" files (.md, .txt, .docx, .pdf), ~1.5 MB. The scenario from the initial requirement.
  - `corpus_versions/` - the same 10 + 5 edited versions (simulates document revisions) - the deduplication scenario.
- `build_extra_corpora.py [real] [binary] [arm64]` - builds the optional corpora that are **not** stored in the
  repository (they are git-ignored):
  - `corpus_real/` - real DOCX / PDF / JPEG files found in installed packages (python-docx template, matplotlib
    PDFs and sample photo, scikit-learn photos, a 100 KB paper PDF from the Cargo registry); the script prints what it found.
  - `corpus_binary/` - x86-64 machine code: a few Windows system DLLs (or Linux shared libraries) plus the `tsaur` release binary.
  - `corpus_arm64/` - ARM64 machine code: the `.so` files of the public `zstandard` wheels (macOS arm64, Linux aarch64), fetched with `pip download`.
- `bench_rust.py` - benchmarks the Rust `tsaur` CLI (release build) on every `corpus*` directory that exists, against
  7-Zip 26.03 (LZMA2 `-mx9` and the defaults, which add BCJ2/ARM64 filters automatically) and WinRAR 7.23 (RAR5 `-m5`
  solid, `-md256m -mcx`) when they are installed; every T-saur round trip is verified bit-exact; writes `RESULTS-rust.md`.
- `two_device_bench.py` - the two-device transfer measurements of `../docs/design/TWO-DEVICE-BENCHMARK-PLAN.md`
  (roles `prepare`, `serve`, `keygen`, `fetch`; results form `TWO-DEVICE-RESULTS-TEMPLATE.md`). Not yet run on two
  devices: a run with both roles on one machine is labelled as a tooling check by the tool itself.
- `../prototype/bench.py` - runs the classic formats (zip/gzip/bzip2/xz/brotli/zstd, plus 7-Zip and WinRAR when they
  are installed) and the T-saur Python prototype (`.tsrp`); writes `RESULTS.md`.
- `check_names.sh` - checks whether a name is free on PyPI / npm / crates.io / GitHub and a few TLDs (used while choosing the project name).
- `out/` - temporary archives generated by the prototype benchmark (can be deleted at any time).

Text provenance: the Python documentation (`pydoc_data/topics.py`, PSF License), Python's `LICENSE.txt`, `idlelib/News3.txt`,
node-gyp's `CHANGELOG.md` and semver's `README.md` (from npm, MIT/ISC), encoding_rs's `README.md` (crates.io, Apache-2.0/MIT).
The DOCX files are generated with python-docx, the PDFs with PyMuPDF (one of them with a synthetic image repeated on several pages).

Run (from the project root):

    python benchmarks/build_corpus.py
    python prototype/bench.py
    cd tsaur && cargo build --release && cd ..
    python benchmarks/build_extra_corpora.py     # optional
    python benchmarks/bench_rust.py

Machine used for the published numbers: Windows 11, 16 threads; single run per variant, times include process start-up.
