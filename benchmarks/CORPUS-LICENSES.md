# Licenses of the benchmark corpus

`benchmarks/corpus/` and `benchmarks/corpus_versions/` contain texts taken from open-source
projects, plus DOCX and PDF documents generated from those texts (`build_corpus.py`). They are
redistributed here only as benchmark inputs; each keeps the license of its source.

| File(s) | Source | License |
|---|---|---|
| `python-docs-part1.txt`, `idle-news.txt` | CPython (`pydoc_data/topics.py`, `idlelib/News3.txt`), Python Software Foundation | PSF License Agreement (the full text is `python-license.txt` in the corpus) |
| `python-license.txt` | CPython `LICENSE.txt` | the license text itself |
| `changelog-node-gyp.md` | node-gyp `CHANGELOG.md` (npm) | MIT, notice below |
| `readme-semver.md` | semver `README.md` (npm) | ISC, notice below |
| `readme-encoding_rs.md` | encoding_rs `README.md` (crates.io) | Apache-2.0 OR MIT (Henri Sivonen and contributors); the Apache-2.0 text is `LICENSE-APACHE` at the repository root |
| `report-A.docx`, `report-B.docx`, `paper-A.pdf`, `brochure-B.pdf` and the `*-v2` edited versions | generated by `build_corpus.py` from the texts above (python-docx, PyMuPDF), with a synthetic image | same licenses as the texts they contain |

The optional corpora (`corpus_real`, `corpus_binary`, `corpus_arm64`) are built on the user's
machine by `build_extra_corpora.py` from files already installed there and are **not**
redistributed with the repository.
